Trial and Purchases

Start a free 30-day trial in Trial and Purchases. The trial ends without a charge. To keep using Finder actions, choose an auto-renewing annual subscription or buy lifetime access in the same app. You can see local prices before and during the trial. Paid purchases open when the trial ends. Manage or cancel your annual plan in your Apple Account. Restore Purchases is available after reinstalling.

Create your first document in Finder

  1. Open QingMenu, then open a local folder on the startup disk in Finder, such as a folder inside Downloads.
  2. Right-click empty space in the Finder window. If you see QingMenu Settings…, the extension is ready. If the item is missing, open the Finder extension controls in QingMenu’s General settings and enable QingMenu in the system list. Right-click in Finder again.
  3. Choose New File → Word. If macOS asks for access, the panel opens in the target folder. Check the folder name and click Allow Access. With the default templates, a new file called New Word.docx appears in the empty folder.

Everyday tasks

Start a document for WPS Office, Pages, Numbers, or Keynote

In Finder, open the folder where you want to work. Right-click empty space and choose New File. Choose WPS Writer or Pages for a document, WPS Spreadsheets or Numbers for a spreadsheet, or WPS Presentation or Keynote for slides. The new file appears in that folder.

WPS documents use .wps, .et, and .dps. Apple documents use .pages, .numbers, and .key. Double-click the new file to edit it in a compatible app. If Finder asks how to open a .dps file, right-click it and choose Open With → WPS Office. In QingMenu’s New File settings, enable the formats you use and turn off any you want to leave out of the menu.

Use a weekly report as a template

Prepare a document with the layout and headings you want to reuse. In New File settings, choose Add Template → Import from File… and select it. In your project folder, right-click empty space and choose the template from New File. Edit the new copy independently. Use the main menu checkbox to reach your template directly from Finder’s context menu.

For a ready-made Word document, choose Add Template → Meeting Notes (Word). In Finder, choose New File → Meeting Notes to create a copy.

Open a file or project folder in a favorite app

In Favorite Apps, click Add Apps… and select an installed application. In Finder, right-click selected files and choose Open with Favorite App, then the app’s name. To send an entire project folder to an editor, right-click empty space inside it and choose Open Current Folder with Favorite App. Choose an app that can open the type of item you selected.

Copy or move files to a project, or just open its folder

Select one or more files, right-click, and choose Copy Files To or Move Files To. Choose a saved destination or select a different folder for this operation. Add frequently used destinations in Send Files To settings.

To jump to a project folder, use Favorite Folders. Finder opens the destination and leaves your selected files in place.

Change a file icon, convert an image, or verify a download

Right-click a file or folder and choose a replacement icon, or restore the default icon. For an image, choose PNG or JPEG conversion in Toolbox to create a separate file alongside the original. For a download, calculate its SHA-256 checksum and paste the result to compare it with the publisher’s checksum.

Common questions

How do I see hidden files in Finder?

Press Shift–Command–period (.) in Finder to toggle hidden items. To make a file or folder you hid with QingMenu visible again, right-click it and choose Unhide Selected Items. Finder also hides names that start with a period, such as .git. Use the same keyboard shortcut to view those items.

How do I reopen settings?

Click the QingMenu icon in the Mac menu bar and choose QingMenu Settings…. When the extension is enabled, the same command is available in the Finder context menu.

How can I tell if the Finder extension is working?

Right-click empty space in a local folder, then right-click a file. Empty space offers commands such as New File. Copy and move commands need a selection. If an individual command is missing, check whether it is enabled in its settings section.

How can I use the menu on a USB drive?

In General, set Finder Menu Scope to Startup Disk + External Disks. Connect the drive and right-click inside one of its folders. If macOS asks for access, check the folder name in the panel and click Allow Access. When creating a file at the top level of the drive, look for the drive name. The drive must support writing for commands that change files. Choose Home Folder Only to limit the menu to your home folder.

Why does the menu appear locally but not in my cloud folder?

Select a file or folder in your cloud drive, then choose Finder → Services → Show QingMenu Actions in the menu bar. Choose a command. To create a document inside a cloud folder, select that folder first. You can also select several files in the same folder.

If the service is missing, use the item picker in QingMenu’s sidebar. For an online-only file, download it in Finder and wait for the download to finish before converting, copying, or moving it.

How do I save clipboard text or an image as a file?

Copy some text from an editor. Right-click empty space in a Finder window or right-click a folder and choose Save Clipboard Text as TXT. To save a screenshot, press Control-Shift-Command-4, drag across the area to copy, then use Save Clipboard Image as PNG.

Copying a file in Finder puts a file reference on the clipboard. Use the file paste command in Toolbox for that case. If the clipboard changes while a menu is open, right-click again to see the commands for its new contents.

How do I save or remove a favorite folder?

Right-click empty space in the folder and choose Add Current Folder to Favorites. You can also right-click a single folder and choose the option to add that selected folder. Open saved folders from Favorite Folders. To remove one, select its row in Favorite Folders in the settings window and click Remove.

How do I manage folder permissions?

If an operation needs access, the panel opens in the target folder. Check the path and click Allow Access to continue. QingMenu remembers the permission. Click Cancel to end the operation. If you switched to Finder, switch back to QingMenu to see the pending panel. To clear saved permissions, open General and click Forget Folder Permissions….

Click Privacy Policy in the settings sidebar for details about local files and clipboard access.
